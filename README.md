# Music Store SQL Project

## About the Project

This project is based on a Music Store database. I used SQL to work with the data and find useful information about customers, sales, tracks, artists, albums, and genres.

The main purpose of this project is to practice SQL and understand how a real-world relational database can be used for data analysis.

## Database Tables

The database contains these tables:

* Artist
* Album
* Track
* Genre
* Media Type
* Customer
* Employee
* Invoice
* Invoice Line
* Playlist
* Playlist Track

## What I Worked On

In this project, I used SQL to answer questions such as:

* Who are the highest-spending customers?
* Which countries have the highest sales?
* Which music genres are most popular?
* Which artists have the most tracks?
* Which tracks have the highest sales?
* What is the total revenue?
* What is the average amount spent by customers?
* Which albums contain the most tracks?

## How to Use

1. Create a database in PostgreSQL.
2. Import the CSV files into the database.
3. Open pgAdmin 4.
4. Run the SQL queries from the `sql` folder.
5. Check the results and use them for analysis.
